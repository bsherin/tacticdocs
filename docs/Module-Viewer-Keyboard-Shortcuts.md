# Keyboard Shortcuts

Keyboard shortcuts for the module viewer, and anywhere else you can edit code. These are listed in the CodeMirror
documentation. The include the [standard keymap](https://codemirror.net/docs/ref/#commands.standardKeymap),
[default keymap](https://codemirror.net/docs/ref/#commands.defaultKeymap) ,
[history keymap](https://codemirror.net/docs/ref/#commands.historyKeymap) ,
[fold keymap](https://codemirror.net/docs/ref/#commands.foldKeymap) ,
and [completion keymap](https://codemirror.net/docs/ref/#commands.completionKeymap) ,
