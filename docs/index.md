Welcome to the TacticText documentation again, a place of wonder and
enjoyment. This is the *documentation* for Tactic. If you want to access tactic itself, then you
should go to <https://tactictext.net>

## New to Tactic?
You might want to start with [Getting Started](Getting-Started.md). This will tell you,
among other things, how to get a user account.

You will be using the {doc}`Library-Interface` to manage your various resources such
as data collections and saved projects. This is where you can [upload your own data](Uploading-Data.md).

Most of the work you'll do, analyzing data, is done in the brilliantly-named [Main interface](Main-interface.md).
There is also a special version of the Main Interface that functions much like a Python Notebook. It's described
in [Logs and Notebooks](Log-And-Notebook.md).

You'll quickly find that you want to make your own tiles. The [Tile Creator](Tile-Creator.md) is
a scaffolded interface for building tiles. The [Module Viewer](Module-Viewer.md) is the
tile-building tool for more advanced python programmers. Admission: I always use the Tile Creator.

When writing your own tiles, you'll need ot make use of the special commands that Tactic makes available
for you. These are documented in [Tile Commands](Tile-Commands.md). To understand more of the nuts and bolts
of how tiles are constructed you can study the section of this documentation
on [Tile Structure](Tile-Structure.md).

You can read about some examples of how Tactic can be used here: <https://repository.isls.org/handle/1/890>.

Tactic makes use of a large number of excellent [open-source resources](open-source-resources.md).
